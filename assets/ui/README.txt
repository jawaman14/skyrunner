  minimap/         Minimap Pack: map markers and frames
  flags/           Flag Pack: country and region flags (the island's neighbours, the Colombians)
  map_pack/        Map Pack: top-down map symbols for the 2D desks
  explosions/      Explosion Pack: sprite sheets for blasts
  emotes/          Emote Pack: speech-bubble emotes
  road_textures/   Road Textures: tiling road surfaces
