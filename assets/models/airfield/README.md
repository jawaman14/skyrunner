# Airfield props (original art)

Eight low-poly props authored for Skyrunner in Blender 5.2 (`windsock`, `beacon_tower`, `fuel_bowser`,
`wheel_chocks`, `tie_down_anchor`, `ground_power_cart`, `runway_edge_light_blue`, `runway_edge_light_white`). Project source licence (MIT, see
the repository `LICENSE`); no third-party meshes, textures or fonts. `windsock`, `beacon_tower`, `fuel_bowser` and
`wheel_chocks` were modelled as parametric CAD (cadgen/build123d) and restyled in Blender; the other four are native
Blender geometry.

* Conventions as `ModelLib`: metres, origin at the base, facing -Z (Godot forward), Y up. 36 to 648 triangles each.
* One material per prop: palette colours only. `airfield_palette.png` (256 x 256, 16 x 16 cells of 16 px) is shared by
  every GLB through a relative URI, so it must stay beside them. Every UV sits on a cell centre; use Filter Nearest.
  Unused cells are magenta so a wrong UV is obvious. The palette is generated by script, not by a third-party
  add-on; its source (palette generator, build scripts, glTF post-process) is kept outside this repository.
* The glTF files carry no emission or metal/rough map (the exporter cannot express them); roughness is 0.9.
* `AirfieldDress` places them as scenery only: nothing here is solid, lit, simulated or random.
